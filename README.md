# Raksha Sutra

Raksha Sutra is a mobile-first personal-safety PWA. It brings together emergency contacts, SOS creation and delivery queues, journey sharing, safe-place discovery, community reports, local helpers (Rakshaks), and a limited admin console.

> This repository is a pilot/prototype. It does **not** currently send a real SMS, email, push notification, or emergency-service request when SOS is triggered. In a live emergency, call **112** directly.

## Start the app

```powershell
npm install
npm run dev
```
